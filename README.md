# Weather App

This Weather App project is a browser-based application built as part of The Odin Project curriculum. This project demonstrates fundamental skills in web development, specifically focusing on asynchronous JavaScript, API integration, and dynamic DOM manipulation.

## Live Demo

Check out the live version of the project here: [Weather App Live Demo](https://andrea441.github.io/weather-app/)

## Description

This project is a practice exercise to test and build competency in:

- Fetching real-time weather data from external APIs using asynchronous JavaScript (`async`/`await` or `fetch`).
- Implementing JavaScript logic to parse JSON responses and update DOM elements in real-time.
- Using CSS Flexbox to create a responsive, user-friendly dashboard layout.
- Adding interactive features like toggling between temperature units (Celsius / Fahrenheit) and search functionality for different locations.

## Technologies Used

- **HTML5:** Used for the basic structure of the application, including the location search form and the weather information display cards.
- **CSS3:** Used for styling and layout. Key concepts applied include:
- **JavaScript (ES6):** Used for the application logic, including:
- **Asynchronous API Calls:** Querying a weather service API to retrieve current conditions and weather forecasts.
- **Event Listeners:** Handling search form submissions, unit toggle clicks, and UI updates.
- **Dynamic DOM Manipulation:** Processing API data and dynamically rendering weather icons, location details, and temperature data.

## How to Use

1. **View Online:** Simply click the [Live Demo](https://andrea441.github.io/weather-app/) link to browse the website.
2. **Run Locally:**

- Clone this repository to your local machine:

```bash
git clone https://github.com/andrea441/weather-app.git

```

- Navigate to the project folder.
- Open `index.html` in your preferred web browser.

3. **Searching:** Enter any city name into the search bar and press Enter or click the search button to load the current weather data.
4. **Settings:** Use the unit toggle button to switch between Celsius (°C) and Fahrenheit (°F).
